# 💱 Currency Converter  

A simple **Currency Converter** project in Python, developed as part of the **Codédex** learning path.  

## 🌍 Supported Currencies  
- 🇧🇷 **Brazilian Real (BRL)**  
- 🇺🇸 **US Dollar (USD)**  
- 🇪🇺 **Euro (EUR)**  
- 🇬🇧 **British Pound (GBP)**  

## 🚀 Project Status  
This project is **a work in progress**. Future updates will include a more dynamic conversion system with real-time exchange rates.  

Stay tuned for more updates!
